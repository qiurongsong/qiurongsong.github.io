# qiurongsong.github.io

Qiurong Song’s academic website, hosted with GitHub Pages.

## Current website

- `index.html`: the single-page homepage, publications, CV, and personal section.
- `onepage.css` and `publications.css`: responsive layout and publication styles.
- `onepage.js`: section navigation and the mobile menu.
- `Qiurong_Song_CV.pdf`: the current downloadable CV (November 20, 2026).

The previous page URLs redirect to the matching homepage sections.

## Older materials and restoration

The [_archive](./_archive/README.md) folder contains complete snapshots of the original website and the previous single-page draft, including its older CV. Its README explains how to restore an individual file or the original website through a new branch and pull request.
